### Задание 1

**Условие:**

Вывести отсортированный в алфавитном порядке список имён пользователей из файла `/etc/passwd`.

**Решение:**

Для получения имён пользователей и их сортировки была использована команда:

```bash
grep -o '^[^:]*' /etc/passwd | sort
```
